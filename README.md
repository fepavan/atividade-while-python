# Gerenciador de Contas e Saldos

Este repositório contém um sistema inteligente para análise e controle financeiro desenvolvido em Python, utilizando a biblioteca **Pandas** para processamento de dados organizados.

## 🚀 Funcionalidades
- **Controle de Acesso Dinâmico**: Validação de usuários em tempo real utilizando laços de repetição `while` interativos.
- **Estruturas Flexíveis**: Armazenamento e manipulação de informações utilizando listas e dicionários otimizados.
- **Análise de Dados**: Leitura de relatórios financeiros a partir de arquivos `.csv` com estatísticas detalhadas.

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- **Pandas**
- **Google Colab**

*Desenvolvido com carinho para fins de aprendizado e evolução profissional.*
